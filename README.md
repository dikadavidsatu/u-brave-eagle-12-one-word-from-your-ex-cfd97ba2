Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward.

This entry's word is **forgettable** — the word an ex uses when you did not even matter enough to hate. A small program scores a shortlist of candidates against the judge's own brief (laugh, sting, instantness, relatability, in that order), validates the winner against the gate — UTF-8 text of 1 to 24 characters, not only white space, exactly one word — and writes exactly that word to `entry.txt`, with no trailing newline and nothing else.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when set, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts` for a local run), then reads the file back and re-validates it before exiting.
